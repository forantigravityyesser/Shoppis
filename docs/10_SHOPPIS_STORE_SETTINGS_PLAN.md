## 1. Обзор
Страница настроек магазина — это основной модуль в интерфейсе продавца, который позволяет управлять метаданными магазина, настройками локализации, каналами связи и публичной видимостью.
В отличие от мастера начального создания магазина, эта страница органично интегрирована во вкладочную структуру главной панели управления и использует утвержденный дизайн-язык "glassmorphism" (стиль glossering).

## 2. Основные принципы UX и архитектуры
- **Блочное управление состоянием**: Страница настроек разделена на логические блоки. Вместо одной глобальной кнопки «Сохранить», **каждый блок отслеживает собственное состояние изменений**. Локальная кнопка «Сохранить» плавно появляется внутри блока только при внесении в него изменений. При отправке сохраняются только те поля, которые относятся к данному блоку.
- **Визуальная согласованность**: Используются существующие карточки в стиле glassmorphism, современная типографика и плавные микроанимации.
- **Модульные компоненты**: Каждый блок настроек будет создан как независимый React-компонент, взаимодействующий с глобальным состоянием магазина (или мутациями React Query).

## 3. Подробная спецификация блоков

### Блок 1: Идентификация магазина (Баннер и Название)
- **Визуальное оформление**: Выделяющийся, красиво оформленный блок в виде хедера.
- **Поля**:
  - **Баннер магазина**: Область загрузки изображения с предпросмотром.
  - **Название магазина**: Текстовое поле ввода с валидацией в реальном времени.
- **Поведение**: Если пользователь изменяет название или загружает новый баннер, внутри этого блока появляется локальная кнопка «Сохранить».
- **Действие в БД**: Обновляет `name` и `banner_url` в таблице `stores`.

### Блок 2: Локализация (Язык и Валюта)
- **Визуальное оформление**: Современные переключатели (Segmented controls) вместо стандартных выпадающих списков.
- **Поля**:
  - **Валюта**: Переключатель из домена (`USD`, `RUB`, `BYN`) с соответствующими иконками/символами. Символ выводится из кода, отдельно не редактируется.
  - **Язык**: Переключатель (например, English, Русский) с ненавязчивыми иконками флагов или кодами языков.
- **Поведение**: При выборе другого варианта появляется кнопка «Сохранить» для данного блока.
- **Действие в БД**: Обновляет `currency` и `language` в таблице `stores` (частично — только изменённые поля блока).

### Блок 3: Статус магазина (Активен / Выключен)
- **Визуальное оформление**: Карточка в стиле glassmorphism с заметным анимированным переключателем (toggle).
- **Поведение**:
  - Переключение немедленно обновляет состояние (или отображает кнопку сохранения).
  - **Активен**: Магазин виден покупателям.
  - **Выключен**: Покупатели, перешедшие по ссылке магазина, увидят красиво оформленный экран «Магазин временно закрыт / на техническом обслуживании». Продавцы при этом сохраняют полный доступ к панели управления и управлению товарами.
- **Действие в БД**: Обновляет `status` (`ACTIVE` / `PAUSED`) в таблице `stores` — отдельной операционной операцией, не смешивается с profile patch. Переход в `PAUSED` сопровождается подтверждением.

### Блок 4: Связь с покупателями (Контакт для связи)
- **Визуальное оформление**: Поле ввода с префиксом в виде иконки Telegram.
- **Семантика**: поле — **общий контакт для связи**, а не обязательно личная ссылка продавца. Продавец может указать свой профиль, контакт менеджера или ссылку на диалог с ботом. Мы не ограничиваем только личной ссылкой.
- **Поведение**:
  - **Строгая валидация и форматирование**: Принимает `@username`, `t.me/username` или просто `username`. При потере фокуса полем или сохранении система удаляет лишние символы и оставляет чистый юзернейм.
  - **Подстановка из Telegram**: в блоке — опциональная кнопка «Подставить мой @username», которая заполняет поле из Telegram-профиля продавца. Подстановка только по явному действию пользователя (не автоматически). Если у продавца нет username — кнопка недоступна.
  - В интерфейсе покупателя это используется для кнопки связи «Связаться с продавцом», ведущей на `t.me/{username}`.
- **Действие в БД**: Обновляет `support_handle` в таблице `stores` (частично — только поле этого блока).

### Блок 5: Поделиться и Предпросмотр (Переход в интерфейс покупателя)
- **Визуальное оформление**: Отлично отполированная карточка «Поделиться».
- **Возможности**:
  - **Ссылка на магазин**: Отображение сгенерированной ссылки для покупателя (только для чтения). Прямой deep link в Mini App (первый шаг — приложение, не чат бота): `t.me/<buyer-bot>/<app-short-name>?startapp=shop_<public_id>` (opaque `public_id`, `03 §26`).
  - **Копирование**: Кнопка копирования в один клик с микроанимацией/тултипом успешного действия.
  - **Предпросмотр**: Кнопка «Предпросмотр магазина», которая ведёт продавца в интерфейс покупателя. Становится активной после появления публичной витрины.
  - **QR-код**: Кнопка быстрого доступа, открывающая QR-код для ссылки на магазин (отложено, не блокирует остальные блоки).
- **Примечание**: Для этого блока не требуется кнопка «Сохранить», так как он предназначен только для чтения и формируется на основе `public_id` и статуса магазина.
